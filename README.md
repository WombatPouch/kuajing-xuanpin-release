# 跨境电商选品助手

跨境电商选品浏览器扩展（Chrome）：支持多个主流平台的选品、选品记录管理，并一键推送至 ERP 渠道。

## 安装

1. 在 [Releases](https://github.com/WombatPouch/kuajing-xuanpin-release/releases) 页面下载最新版本的 `kuajing-xuanpin-<版本号>-chrome.zip`
2. 打开 Chrome，地址栏访问 `chrome://extensions/`
3. 开启右上角的 **开发者模式**
4. 将下载好的 zip 文件直接拖拽到页面中即可完成安装

## 更新

扩展启动时会自动检测新版本，检测到后展示升级提示与下载地址；也可以随时在本页面 Releases 中手动下载最新安装包重新加载。
